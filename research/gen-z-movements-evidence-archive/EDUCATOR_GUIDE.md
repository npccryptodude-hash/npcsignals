# educator / reader guide

## how to use this archive

this archive can be used for source criticism, civics, political science, history, media literacy and comparative social-movement analysis.

students should begin with one case file and then check the evidence ledger before making broader comparisons.

## suggested study questions

1. what was the original trigger?
2. who organized the first visible actions?
3. how did information spread?
4. when did established organizations enter?
5. how did the state respond?
6. did violence change public interpretation of the movement?
7. did the movement build durable organization?
8. did it enter elections?
9. did electoral success produce institutional change?
10. which claims remain unresolved?

## source criticism exercise

for any claim:

- identify the original source;
- classify it as primary, official, monitoring, academic or journalistic;
- check whether a second independent source exists;
- distinguish observation from interpretation;
- record whether the claim should be CONFIRMED, SUPPORTED, CONTESTED, UNRESOLVED or NOT ESTABLISHED.

## comparative assignment

compare thailand, bangladesh and serbia using the four-power model:

- mobilization;
- organization;
- elections;
- institutions.

then answer:

**why can a movement win the street but lose the political aftermath?**

## important caution

the archive documents political movements. it does not tell readers which political outcome to support.

the objective is to understand systems, evidence and mechanisms.
