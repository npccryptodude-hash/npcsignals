# Tennessee Execution Protocol Stress Test — Christa Pike (2026)

**Status:** DRAFT  
**Freeze:** 2026-10-01  
**Scope:** Tennessee's published lethal-injection protocol, the failed execution attempt of Christa Pike on 2026-09-30, and the protocol endpoint reached after the backup procedure was used.

## Research question

What did Tennessee's execution protocol require, what contingency did it provide if the primary pentobarbital set failed, and what did the protocol specify if the backup set also failed to produce death?

## Core finding

Tennessee's protocol contained a primary pentobarbital set and a backup set. After the 2026-09-30 execution attempt, the Tennessee Department of Correction stated that it had followed every step of the state's established protocol, that the protocol did not allow additional procedures beyond those carried out that evening, and that Christa Pike had been transported to an off-site medical facility.

The strongest documented system-level finding is therefore narrow:

> Tennessee had a contingency for failure of the primary execution procedure, but the published protocol did not provide another execution step after the backup procedure was exhausted.

This does **not** establish why the execution failed.

## Classification

- **CONFIRMED:** Tennessee used a single-drug pentobarbital protocol.
- **CONFIRMED:** The protocol contained Primary Set A and Backup Set B.
- **CONFIRMED:** Pike's pre-execution filings specifically raised the absence of medical care, resuscitation, or emergency intervention after a failed execution and identified Set B as the protocol's contingency after Set A.
- **CONFIRMED:** After the attempt, TDOC said every step of the protocol had been followed.
- **CONFIRMED:** TDOC said the protocol did not allow additional procedures beyond those carried out.
- **CONFIRMED:** Pike was transported to an off-site medical facility.
- **UNRESOLVED:** Why the drug procedure failed.
- **UNRESOLVED:** Whether the full intended dose reached systemic circulation as intended.
- **UNRESOLVED:** Whether IV access, drug preparation, administration, physiology, or another factor explains the outcome.
- **NOT ESTABLISHED:** That pentobarbital itself was ineffective.

## Important distinction

The 2026 Tony Carruthers execution attempt and the Pike case should not be treated as identical.

- **Carruthers:** the execution was abandoned after required IV access could not be established.
- **Pike:** TDOC says it completed every step permitted by the established protocol, yet the intended outcome did not occur.
