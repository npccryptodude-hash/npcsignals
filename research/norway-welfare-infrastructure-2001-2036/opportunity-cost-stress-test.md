# Opportunity-Cost Stress Test: Financial Saving vs. Public Capital

Freeze date: **2026-10-01**

## Claim tested

A recent public argument by Finance Minister Jens Stoltenberg is that money Norway chose to save rather than spend in the 1990s has multiplied substantially inside the Government Pension Fund Global.

VG reported the same argument in 2026: Stoltenberg used Norway's decision to save petroleum revenues as evidence that avoiding current spending can create substantially larger financial wealth for future generations.

Source:  
https://www.vg.no/nyheter/i/lnvm9e/stoltenberg-britene-kunne-hatt-7-000-milliarder-kroner

NBIM confirms that the first transfer to the fund was made in 1996 and that the fund's purpose is to preserve and develop financial wealth for current and future generations.

Source:  
https://www.nbim.no/no/om-oss/om-oljefondet/

## What the saving argument gets right

The opportunity cost of spending is real.

If NOK 1 billion is spent today instead of invested, Norway gives up the future financial return that the capital could have earned.

This is particularly relevant for:
- ordinary current consumption;
- projects with weak or uncertain public value;
- investments undertaken when domestic capacity is already constrained.

The research therefore does **not** treat financial saving as passive or valueless.

## What the argument does not settle

The comparison becomes incomplete when the alternative use of funds is productive public capital.

The relevant comparison is not:

> **save NOK 1bn → larger financial wealth later**

versus

> **spend NOK 1bn → zero value later**

For infrastructure, the proper comparison is closer to:

> **save NOK 1bn → financial asset + future investment return**

versus

> **invest NOK 1bn → public physical asset + avoided future deterioration + possible operating savings + service value − foregone financial return**

The second side is harder to measure, but it cannot be assumed to equal zero.

## Public-capital opportunity cost

Deferring a necessary rehabilitation project can create its own opportunity cost through:

- higher future construction cost;
- secondary damage;
- emergency repair;
- shorter useful life;
- higher energy cost;
- operational disruption;
- more expensive later replacement.

That means there are two forms of compounding:

### Financial compounding
Saved capital earns investment returns.

### Technical compounding
Deferred maintenance can increase future physical liabilities.

The policy problem is therefore a comparison between two compounding processes, not simply "saving" versus "spending".

## Decision rule

A restoration project should not be funded merely because Norway has money.

Nor should it automatically be postponed merely because the money could earn a financial return.

A stronger decision rule is:

> **Fund restoration when the expected long-term public value of acting now exceeds the expected value of delay after accounting for foregone financial return, macroeconomic pressure and project risk.**

## Practical test for each project

For major projects, compare:

1. current rehabilitation cost;
2. expected cost if delayed 5–10 years;
3. probability and cost of secondary damage;
4. operating-cost changes;
5. expected useful-life extension;
6. service continuity / disruption effects;
7. alternative financial return if funds remain invested;
8. labour and construction-capacity conditions.

This converts the debate from:

> "Should Norway save or spend?"

to:

> **"Which use of capital creates the stronger long-term public balance sheet?"**

## Status

**SUPPORTED AS A DECISION FRAMEWORK**

The research does not claim that public infrastructure investment generally outperforms GPFG returns.

It claims only that a valid opportunity-cost analysis must value both sides:

- foregone financial returns from spending;
- foregone public-asset value and higher future liabilities from delaying necessary investment.

## Implication for the 2027–2036 programme

The ten-year programme should include an explicit **Cost of Delay** field in project scoring.

A project moves up the priority list when delay is expected to:
- materially increase future cost;
- create secondary damage;
- shorten useful life;
- increase operating costs;
- threaten service continuity.

This strengthens the existing prioritisation model without weakening the fiscal-rule framework.
