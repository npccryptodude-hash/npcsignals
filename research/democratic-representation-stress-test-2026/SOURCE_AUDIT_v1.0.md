Purpose

This audit checks four things before the seven MIS scoring fields are populated:

1. temporal eligibility;
2. existence of at least one primary or high-quality source path;
3. category fit under the 2 + 2 + 2 case design;
4. duplication / non-independence risk between cases within the same country.

Audit labels

READY — source path and case definition are sufficiently clear for scoring.
TIGHTEN — case is usable, but the source pack or case wording should be narrowed before scoring.
DESIGN REVIEW — evidence exists, but category fit or independence from another case needs review.
PENDING — event not yet finally certified.

Important

This is not a scoring document. No MIS value is assigned here.
