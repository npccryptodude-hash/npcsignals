## Scoring lock

Numerical rescoring begins only after the Swedish Election Authority formally determines the 2026 Riksdag result, unless a later version explicitly changes that rule before scores are calculated.

When scoring opens:
1. all 90 cases are scored from scratch;
2. no pilot score is carried forward automatically;
3. the seven frozen 0–4 variables are used unchanged;
4. the original first-pass score is preserved before any second pass;
5. second-pass review cannot silently overwrite first-pass judgments;
6. sensitivity analysis is run only after the main ledger is frozen;
7. non-compensatory safeguard testing is reported separately from the base arithmetic mean.
