# archive quality and preservation plan

baseline: `75fcb4966e4c21590cce363fcff2d94641d41257` · 15 november 2026

## scope and dependencies

the baseline contains 6,469 tracked files. the full path inventory, markdown links, duplicate bytes, checksum manifests and script path references were examined before navigation changes. the work is documentation maintenance, not new research or a new assessment of the underlying claims.

## planned changes

1. replace the conceptual homepage with the project identity and a direct research entrance.
2. give each research subject one reader entrance, with purpose, documented scope, uncertainty, work status and evidence links. use descriptive labels instead of internal case codes.
3. keep all original evidence, dated checkpoints, scripts, transaction identifiers and manifests at their existing paths. consolidate navigation rather than moving frozen material.
4. distinguish the binance incident reconstruction from the unrelated binance exchange-attribution evidence. group zyrox's post-freeze records under its reader entrance.
5. correct editable navigation defects; document broken links inside frozen copies using a separate resolution guide.
6. provide a separate, offline gamdom compatibility runner that recreates the historical layout in disposable local copies. never patch frozen scripts or regenerate their manifests in the public archive.
7. separate current reader guidance from historical researcher instructions. preserve dated methodological limits, corrections and provenance.
8. record baseline integrity failures and bounded validation results honestly. a known failure is not converted to a pass by changing a reference checksum.

## preservation classes

| class | treatment |
| --- | --- |
| original responses, captures, receipts, zip bundles and immutable source copies | preserve bytes and paths |
| manifest-covered reports, code and dated checkpoints | preserve; link through current reader pages |
| historical non-manifest checkpoints and revision trails | retain dates, ids and substantive content |
| current homepage, research index and new reader guides | edit with relative links and lowercase editorial text |
| potential credentials or private information | do not duplicate; report privately for ownership review and rotation if applicable |

## release boundary

use a dedicated branch and pull request. no history rewriting, automatic deletion of evidence duplicates, research reclassification, website change or external publication. unresolved integrity or credential questions block a claim of complete acceptance. unmerged research branches remain explicitly separate from the main archive.
